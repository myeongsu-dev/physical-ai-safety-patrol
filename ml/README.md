# AI 학습

| 모델 | 클래스 | 담당 | 폴더 |
|---|---|---|---|
| 안전모 | person · head · helmet | 채웅, 이예은 | `helmet/` |
| 불꽃 | fire | 박명수, 김건주 | `flame/` |

`person`은 안전모 판정(사람 → 머리 → 안전모)과 막힘에서 사람을 빼는 데 함께 씁니다. Pi의 `edge/detect.py`가 두 모델을 모두 불러 씁니다.

## 흐름

1. **데이터**: 공개 데이터(Roboflow · Kaggle · AI Hub · COCO) + 미션맵에서 XIAO로 찍은 사진. ESP32 카메라 화질 사진을 꼭 섞습니다. 클래스별 사진 수를 비슷하게 맞춥니다.
2. **라벨링**: 넷이 함께. 자동 라벨 결과를 무작위로 골라 사람이 검수합니다.
3. **학습**: 노트북 또는 Colab GPU, 작은 YOLO(nano). 노트북·스크립트는 각 폴더에 둡니다.
4. **변환·배포**: Pi 5 CPU용 NCNN으로 변환(입력 320~640)해 `models/<모델>-v<번호>/`에 넣고 커밋합니다. 속도가 모자라면 Hailo-8L을 검토합니다.

## 지킬 것

- 데이터(`data/`)와 학습 중간 결과(`runs/`)는 커밋하지 않습니다. 데이터는 공유 드라이브에 두고 출처와 받는 법을 각 폴더 README에 적습니다.
- 모델을 바꾸면 `models/`에 새 번호로 넣고, 이전 번호는 시연 전까지 남깁니다.
- 각 폴더 README에 데이터 출처·장수, 학습 설정, 결과(mAP, Pi 5에서 초당 장수)를 적습니다.

```bash
pip install -r ml/requirements.txt
```
